# Historical PostgreSQL implementation

These files preserve the previous PostgreSQL migrations, VPS deployment and local tooling for reference. They are not compatible with the current MongoDB schema and must not be run as deployment/setup commands. Some historical scripts retain their original relative paths and dependencies. Recover the complete PostgreSQL release from commit 730bec0d7e9ef707e7924aad7943284f5af0c24b if needed. Existing local PostgreSQL data has not been moved or deleted.
